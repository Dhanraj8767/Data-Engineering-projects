# Retail Sales Dataset

This folder contains the raw retail sales dataset used for the Retail Sales Data Engineering Pipeline.

**Purpose:**
- Store raw retail sales data in CSV format.
- Use the dataset as input for PySpark ETL processing.
- Perform data cleaning and validation.
- Transform raw data into Bronze, Silver, and Gold layers.
- Generate sales insights for Power BI dashboards.

**Technology:** Python, PySpark, SQL, Delta Lake, Azure Databricks.
